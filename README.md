# Shivani — Kid Birthday React Frontend

Cute, animated birthday website built with React + Vite + Framer Motion + Lucide icons.

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included
- 7 supplied photos
- Responsive mobile-first layout
- Cute floating doodles
- Animated transitions with Framer Motion
- Interactive birthday reveal
- Confetti celebration
- Photo lightbox
- Heart-touching letter
- Cute cartoon-style emoji/sticker elements
